# 🍷 Guapiko AI Studio Site

**"Agencia de Futuro"**
Официальный репозиторий корпоративного сайта Guapiko AI Studio. Мы специализируемся на разработке автономных ИИ-агентов, кастомных LLM-интеграций, автоматизации бизнес-процессов и AI-driven решениях.

## 📖 Документация
- **GDD & Tech Spec:** Вся техническая философия, правила разработки (H1/H2/H3 семантика) и подход к верстке описаны в [GDD.md](./GDD.md).
- **SEO Схема:** Полная структура URL, хабов (Level 2) и посадочных страниц (Level 3) с региональным таргетингом описана в центральном артефакте агентов `seo_url_schema.md`.

## 🛠️ Стек технологий
- **Backend & Routing:** PHP (Собственный легковесный роутер в `public/index.php`).
- **Сборщик:** Vite.
- **Стилизация:** SCSS (с активным использованием BEM, Nesting и конфигурационных переменных).
- **UI Библиотека:** Showroom (Все компоненты сначала тестируются здесь).

## 🚀 Запуск проекта

### 1. Установка зависимостей
```bash
npm install
```

### 2. Режим разработчика (Vite Dev Server)
```bash
npm run dev
```
*Внимание:* Vite отвечает только за горячую перезагрузку стилей и скриптов. Для рендера PHP-страниц у вас должен быть запущен локальный сервер (например, Laragon, XAMPP или встроенный PHP сервер), указывающий на папку `public/`.

### 3. Сборка для Production
```bash
npm run build
```
Собранные и минифицированные файлы появятся в директории `public/dist/`.

## 🧩 Пайплайн разработки (Component Assembly)
Сайт строится **только** из независимых компонентов:
1. Для новой секции создайте `_component.scss` и `_component.js` в `src/assets/`.
2. Подключите и протестируйте их в `App/views/es/showroom.php`.
3. Соберите итоговую страницу (например, `/inicio`), импортируя готовые стили и JS-функции в соответствующие файлы страницы (`inicio.scss` / `inicio.js`).
